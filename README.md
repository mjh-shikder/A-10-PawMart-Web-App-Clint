# PawMart 🐾

[Live Site](https://deluxe-wisp-ccab1f.netlify.app/)  

**PawMart** is a community-driven platform where pet lovers, breeders, and shops can list pets for adoption or sell pet-related products like food, toys, and accessories. Buyers and adopters can browse, contact sellers, and order products directly through the platform.

## Features

- 🐶 **Pet Adoption**: Browse and adopt pets from trusted sources instead of buying, helping rescue animals find loving homes.  
- 🍖 **Pet Products Marketplace**: Purchase high-quality pet food, toys, accessories, and care products easily.  
- 📍 **Location-Based Listings**: Filter products and pets by location for faster and convenient access.  
- 💌 **Direct Contact & Orders**: Contact sellers directly and place orders for products or adoption requests seamlessly.  
- 🌟 **User-Friendly Interface**: Clean and intuitive design using Tailwind CSS for an enjoyable browsing experience.  
- 🧸 **Category Filters**: Easily filter pets, food, accessories, and care products for a more personalized search.  
- 📆 **Pickup & Delivery Options**: Schedule pickup or delivery dates for your orders and adoptions efficiently.  

## Technologies Used

- Frontend: React, Tailwind CSS  
- Backend: Node.js, Express.js  
- Database: MongoDB  
- API Communication: Axios
